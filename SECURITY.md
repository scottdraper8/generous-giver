# Security policy

This repository is a data-mod scaffold and currently has no game payload. Please report vulnerabilities in its CI, installer metadata, or dependency setup privately through [GitHub's security advisory form](https://github.com/scottdraper8/generous-giver/security/advisories/new). Do not include credentials, private save files, or copyrighted game assets in a report.

Dependabot security pull requests require CI and human review. They are not configured to merge automatically.
